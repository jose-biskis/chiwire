# Chiwire design system

UI documentation by **archetype**. New projects use **Internal** by default.

**Base** is a hidden contract layer (shared catalog + variant names) — see **Base → Overview**.
Product apps import `@chiwire/ui/internal` or `@chiwire/ui/valenstonic`, not base. Brand-only UI
lives in each archetype’s `exclusive/` folder.

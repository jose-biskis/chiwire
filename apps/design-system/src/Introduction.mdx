# Chiwire design system

UI documentation by **archetype**. New projects use **Internal** by default.

## Archetypes

| Archetype | Use when |
|-----------|----------|
| **Internal** | Internal tools, dashboards, new apps without a brand kit |
| **Valenstonic** | Valen's Tonic / Academy marketing and product UI |

Browse **Archetypes → Internal** or **Archetypes → Valenstonic** in the sidebar.

## Deployed preview

After deploy, tunnel like Grafana / Bull Board:

```sh
npm run deploy:design-system
npm run tunnel:design-system
```

Open http://localhost:3050
